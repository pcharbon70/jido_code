# Milestone F Plan - Knowledge And Wiki Lenses

This five-phase plan exposes the factory's graph domains through named,
reviewed, bounded, provenance-bearing product lenses. It builds accessible
table/tree/timeline/matrix/small-network components; then delivers source,
project-domain, execution, evidence, memory, wiki/dependency, security/audit,
dataset, and derived-diagnostic experiences without raw SPARQL or unrestricted
graph traversal.

Back to program: [Secure Hypermedia Control Plane UI](../README.md)

## Goal

Close program Gate HUI6 with useful, secure, accessible graph understanding for
humans and agents. Repository wikis remain isolated opt-in compiled projections;
their Mix/dependency information, user/developer guides, maintainer status,
preview isolation, token usage, attributable cost, and budgets are visible
without granting publication or command authority.

| Phase gate | Required result | Phase |
|---|---|---|

## Parallelism And Boundaries

After the registry/query envelope and visualization contracts are pinned,
disjoint lens families may develop in parallel under separate route/query/
component ownership. Shared query templates, authorization, visualization, or
export modules have one phase owner. Parallel repository wiki previews remain
isolated and cannot race the one-current-edition fence or bypass repository
enrollment/budget policy.

## Completion Definition

Milestone F completes when every enabled graph family has an approved lens or
explicit unavailable posture; every view is bounded, provenance-rich, scoped,
accessible, and revocable; no raw query/traversal path exists; wiki and Mix
dependency knowledge is complete and correctly labeled; sensitive memory/audit
content is minimized; and export cannot widen the view's authority.
