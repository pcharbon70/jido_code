# Milestone F Phase 5 - Graph Isolation, Usability, And Acceptance

This phase qualifies all enabled lenses across real graph adapters, hostile and
large data, role boundaries, accessibility, task usability, export, revocation,
live delivery, and recovery.

Back to plan: [README](./README.md)

- [ ] 5 Phase - Accept the reviewed knowledge and wiki lens portfolio.

  This phase closes HUI-F5 and HUI6 only when every enabled graph domain has a
  useful governed presentation and no unrestricted alternate path exists.

  - [ ] 5.1 Section - Complete isolation, security, and capacity qualification.

    This section attacks cross-scope inference and resource exhaustion across
    queries, joins, visualizations, live updates, details, and exports.

    - [ ] 5.1.1 Task {#huif-p05-security} [repo: jido_code] [after: {#huif-p04-phase-receipt}] - Execute the full lens threat and large-data matrix.

      This task validates graph-family isolation at every entry and continuation
      boundary using several principals, repositories, previews, and grants.

      - [ ] 5.1.1.1 Subtask - Test IDOR/inference through refs, labels, links, provenance, counts/facets, pagination, errors/timing, cache, subscriptions, details, exports, downloads, and derived rankings.
      - [ ] 5.1.1.2 Subtask - Test signal/query injection, raw SPARQL/internal access, arbitrary graph/predicate/path/join/traversal, hostile Markdown/HTML/CSV/JSON/filenames/URLs, and formula/link attacks.
      - [ ] 5.1.1.3 Subtask - Load/soak maximum rows/pages/depth/nodes/edges/series/bytes/time, concurrent lenses/exports/streams, expensive search, cancellation, timeout, backpressure, and cleanup.
      - [ ] 5.1.1.4 Subtask - Test role/delegation/project/graph/session revocation during query, render, stream, export generation/retrieval, preview inspection, and protected detail.

  - [ ] 5.2 Section - Complete accessibility and task-usability qualification.

    This section proves developers, knowledge stewards, reviewers, security
    auditors, cost observers, and operators can answer real questions correctly.

    - [ ] 5.2.1 Task {#huif-p05-human} [repo: jido_code] [after: {#huif-p05-security}] - Validate knowledge tracing, dependency, graph, and wiki scenarios.

      This task measures comprehension and correct decisions, not merely view
      rendering or component conformance.

      - [ ] 5.2.1.1 Subtask - Test tracing source/domain/evidence/memory/wiki statements to provenance, recognizing stale/contradictory/truncated data, and finding relevant execution/evidence context.
      - [ ] 5.2.1.2 Subtask - Test direct/transitive Mix dependency posture, wiki guide/navigation/opt-out/cost/maintainer interpretation, sensitive-area boundaries, and dataset readiness.
      - [ ] 5.2.1.3 Subtask - Run keyboard, supported screen reader, zoom/reflow, touch, RTL, reduced motion, forced colors, no-JS, print, live updates, and every graph alternative.
      - [ ] 5.2.1.4 Subtask - Measure task success, critical interpretation errors, time to answer, provenance recognition, truncation awareness, graph-navigation burden, and confidence against thresholds.

  - [ ] 5.3 Section - Assemble the accepted lens and graph-coverage baseline.

    This section reconciles coverage, query/visual/export registries, wiki and
    sensitive-domain evidence, operations, rollback, and residual risk.

    - [ ] 5.3.1 Task {#huif-p05-release} [repo: jido_code] [after: {#huif-p05-human}] - Publish the HUI6 lens coverage and qualification dossier.

      This task freezes exact enabled lenses and marks all others unavailable
      rather than leaving ambiguous partial product exposure.

      - [ ] 5.3.1.1 Subtask - Reconcile all graph families to lens/query/view/detail/export/subscription/authorization/owner/readiness/evidence or explicit unavailable posture.
      - [ ] 5.3.1.2 Subtask - Reconcile visualization/accessibility alternatives, query/resource limits, isolation/inference, wiki/dependency/accounting, sensitive lenses, and operational capacity.
      - [ ] 5.3.1.3 Subtask - Rehearse disabling individual lenses/exports/live updates to the accepted prior product without affecting graph truth, attempt controls, wiki state, or retained audit/accounting.
      - [ ] 5.3.1.4 Subtask - Create `hypermedia-ui-milestone-f-phase-05-receipt.md` in merge-pending state with HUI-F5/HUI6 evidence and reopening conditions.

  - [ ] 5.4 Section - Phase 5 Integration Tests.

    This final section reruns the complete lens portfolio at the exact candidate
    with real adapters, roles, large data, assistive technology, and faults.

    - [ ] 5.4.1 Task {#huif-p05-integration} [repo: jido_code] [after: {#huif-p05-release}] - Execute the HUI-F5/HUI6 end-to-end acceptance matrix.

      This task closes Milestone F only when usefulness and strict isolation
      both hold across every enabled graph domain.

      - [ ] 5.4.1.1 Subtask - Run all source/domain/execution/evidence/cost/derived/wiki/dependency/memory/security/audit/incident/dataset lens, detail, export, live-update, and recovery scenarios.
      - [ ] 5.4.1.2 Subtask - Run cross-scope/inference, hostile content, raw-query/traversal, limit/load/soak/cancellation, revocation, adapter outage, restart, cache, and rollback scenarios.
      - [ ] 5.4.1.3 Subtask - Run complete supported-browser/manual-accessibility and role-usability scenarios with exact production assets/configuration and declared metrics.
      - [ ] 5.4.1.4 Subtask - Run all Milestone F and prior regression suites, architecture/security/a11y checks, `mix precommit`, and clean-checkout CI.

    - [ ] 5.4.2 Task {#huif-p05-phase-receipt} [repo: jido_code] [after: {#huif-p05-integration}] - Publish and pin the Phase 5 receipt and HUI6 closure.

      This task records HUI-F5/HUI6 evidence in
      `docs/architecture/hypermedia-ui-milestone-f-phase-05-receipt.md`.

      - [ ] 5.4.2.1 Subtask - Keep HUI6 merge-pending on uncovered enabled graph, raw/unbounded access, cross-scope inference, unsafe export/content, inaccessible meaning, failed usability threshold, wiki/accounting error, or rollback failure.
      - [ ] 5.4.2.2 Subtask - Record exact candidate/catalog/query/view/browser/AT/load/security/usability/rollback evidence, exceptions, limitations, and every reopening condition.
      - [ ] 5.4.2.3 Subtask - Pin the full merged SHA/date and check the phase, Phase 5 Integration Tests section, receipt task, pinning subtask, and Milestone F completion before authorizing Milestone G Phase 1.
