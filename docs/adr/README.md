# Architecture Decision Records

Architecture decisions use sequential identifiers and one of these statuses:
`Proposed`, `Accepted`, `Superseded`, or `Rejected`.

Accepted decisions are binding on implementation and tests. A later decision
may supersede an ADR only by naming it and documenting migration and rollback
consequences.
