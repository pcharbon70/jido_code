# Ontology release 1.4.0

This additive release defines immutable delegated adapter releases, delegated
agent profiles, expiring readiness observations, and their closed vocabulary.
It preserves ontology 1.3.0 as its base and grants no authority to runtime
processes, provider output, catalog projections, or legacy
`developer_local_cli` input. The legacy term remains available only when
reading historical adapter-boundary data; new semantic commands emit
`developer_local`.
