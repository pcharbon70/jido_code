# Jido Factory Ontology 1.3.0

This additive release imports the immutable `1.2.0` segmented-execution
contract and defines the managed coding profile, strategy revision, bounded
runtime observation, budget snapshot, clarification, candidate-completion
proposal, and candidate-handoff terms used by semantic command line `2.8.0`.

The new resources remain in the existing `factory_policy`, `run_attempt`, and
`run_event_segment` graph families. The release creates no new persistence
plane and grants no model, agent, Pod, runtime, verifier, publication, or merge
authority. Legacy ontology/shape pairs remain immutable and readable.
