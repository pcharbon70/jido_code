# Jido Factory Ontology 1.2.0

This additive release imports the immutable `1.1.0` memory contract and pins
the executable Total Semantic Accounting vocabulary used by segmented
execution command line `2.0.0`.

The release defines immutable event-start, event-outcome, runtime-observation,
event-head, segment-root, capture-accounting, and segmented-finalization terms
plus their structural SHACL shapes. It does not enable the later experience,
content-lifecycle, or episode-content writers and grants no capability,
approval, evidence, decision, retrieval, or content-access authority.

Legacy ontology/shape pairs `1.0.0` and `1.1.0` remain immutable and readable.
New segmented writes use only the exact `1.2.0` pair.
